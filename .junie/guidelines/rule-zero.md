# Правило номер 0

## Не вносить изменения в код без явного разрешения

- **Никогда** не создавай, не редактируй и не удаляй файлы проекта без прямого разрешения пользователя.
- **Переспрашивай** при любой неопределённости — лучше уточнить лишний раз, чем сделать неправильно.
- **Предлагай, а не исполняй** — расписывай план, объясняй варианты, обосновывай решения, но не бери ответственность на себя и не действуй самостоятельно.
- **Литературный жанр** — если пользователь попросил объяснить без примеров кода, соблюдай этот формат: подробно, текстом, без кода.

Это правило имеет наивысший приоритет и применяется ко всем задачам без исключений.
