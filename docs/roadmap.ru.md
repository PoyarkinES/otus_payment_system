# Otus Payment System — Roadmap

## Цель
За 6 месяцев поэтапно собрать реалистичную fintech-систему на .NET.

---

## Этап 1. Базовая платформа
**Срок:** 1 месяц

### Неделя 1
- Создать каркас репозитория
- Определить структуру проекта
- Подготовить папки под Clean Architecture
- Зафиксировать bounded contexts

### Неделя 2
- Реализовать регистрацию
- Реализовать логин
- Добавить JWT-аутентификацию

### Неделя 3
- Добавить роли пользователей
- Подключить PostgreSQL
- Настроить Entity Framework Core
- Создать миграции

### Неделя 4
- Добавить Swagger / OpenAPI
- Добавить валидацию
- Добавить базовые тесты
- Закрыть этап

**Результат:** пользователь может зарегистрироваться и войти в систему.
